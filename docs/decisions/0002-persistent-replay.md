# ADR 0002：采用永久回看与独立对象存储

## 状态

已采纳，取代 ADR 0001。账号、提交和回看权限部分已由 [ADR 0003](0003-github-workspaces.md) 取代；以下内容保留为历史决策，持久化存储与显式删除原则继续适用。

## 决策

Koma 将每次分析保存为可永久回看的任务。公开用户免登录提交，并通过不可猜的 `/jobs/<id>` 链接返回；匿名 HttpOnly 浏览器身份负责列出和删除当前浏览器提交的任务，`/admin` 负责全局 Provider 和任务管理，不引入完整用户账号系统。

SQLite/MySQL 保存任务状态、分析要求、完整 JSON 结果和对象索引；本地持久目录或阿里云 OSS 保存原视频、关键帧和生成文件。所有对象位于 `koma/jobs/<id>/`，中间音频和工作目录在处理后删除。

## 结果

- 服务重启后完成任务仍可回看，多实例可共享数据库与 OSS。
- 只有公开链接不能删除数据；任务提交者与管理员删除时会同时清理数据库和整个对象目录。
- 需要运营侧关注存储成本、公开演示限流和敏感内容治理。
- 运行中任务暂不自动续跑；服务重启后标记为失败，用户可以重新提交。
